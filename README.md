# ALL WORLD BRANDS V3
A real backend-backed starter for allworldbrands.net.

Run: install Node.js 20+, `npm install`, then `npm start`, open http://localhost:3000.

Included: Express API, local SQLite DB, countries, starter brands, search, country/brand pages, factory data model, brand-owner application storage, responsive frontend.

Production work still required: PostgreSQL, authentication/roles, file storage, payments, maps, moderation/audit logs, rate limiting/CAPTCHA, email verification, full country/brand dataset with sources, legal pages, HTTPS/DNS deployment.
